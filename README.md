# Prima di Dormire

Landing page ufficiale del progetto **Prima di Dormire**: podcast, racconti, musica e libro.

## Sviluppo locale

```bash
npm install
npm run dev
```

Aprire `http://localhost:3000`.

## Contenuti

Titoli, descrizioni e link principali sono raccolti in:

```text
src/content/site.ts
```

I collegamenti esterni sono ancora placeholder (`#`) e verranno sostituiti con gli URL definitivi di Spotify, SUNO e Amazon.

## Deploy

Il progetto usa Next.js con App Router ed è pronto per il deploy su Vercel e per il dominio `primadidormire.eu`.
